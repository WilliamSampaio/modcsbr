1. VHE can be downloaded in Steam with Half-Life SDK: steam://install/254430/
2. Hammer 3.5 can be downloaded: https://twhl.info/wiki/embed/Valve_Hammer_Editor_3.5
3. Download ZHLT - Direct Links to 3.x and 5.xx Beta Builds: https://downloads.ammahls.com/zhlt/zhlt34_final_sse2_v2.zip
4. Extract the Valve_Hammer_Editor_3.5 in this folder: C:\HammerGoldSource35 (You should create)
5. Extract the zhlt34_final_sse2_v2.zip in this folder: C:\HammerGoldSource35\ZonerHalfLifeTools (You should create)
