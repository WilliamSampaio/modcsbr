# Specs

Specs describe planned gameplay, weapon, server, and mod changes before implementation.

## Workflow

1. Draft the idea in `specs/backlog`.
2. Move it to `specs/approved` when the behavior is agreed.
3. Move it to `specs/implementing` while code is being changed.
4. Move it to `specs/completed` after the feature is tested in game.

## Suggested Template

```md
# Feature Name

## Goal

## Player-Facing Behavior

## Technical Notes

## Test Plan
```
